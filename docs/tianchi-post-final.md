## 二、作品是什么

「**馗判**」——面向大学生的合同防坑助手。

把租房、实习/兼职合同上传或粘贴进来（也支持直接拍合同照片），它会逐条帮你检查：

- **逐条风险识别**：原文高亮命中条款，左侧红黄绿目录一眼扫完全篇；
- **白话解释**：这条在说什么、坑在哪，不说术语；
- **法律依据**：每条依据都是法条原文逐字核对、附官方来源链接——**不是 AI 编的**，模型在这个产品里无权生成任何法条；
- **签约前话术**：拿着这句话去问房东/HR，问什么都替你想好了；
- **条款改写建议**：这段该改成什么样（标注 AI 生成，仅供参考）；
- **陷阱库 + 签约前检查清单**：押金没收、违约金翻倍、培训贷……按类型浏览真实脱敏案例，清单可勾选、可截图保存（案例来自公开报道与用户脱敏反馈）。

顶部概览卡直接告诉你：这是什么合同、月租押金违约金多少、总体是"**需重点留意**"还是"**暂未发现明显风险**"。

馗判的定位很克制——**不替代律师审查，只做签约前的那一道自查**。本工具由学生团队开发，用于提示合同中可能存在的风险，不构成法律意见，不能替代律师或专业机构的审查。最终是否签约，请你自己判断，必要时拨打 12348 法律服务热线，或向你所在学校的法律援助中心、法学院咨询。

## 三、为什么做

大学生第一次独立签合同的场景高度集中：**租房、实习、兼职**。而这些恰恰是坑最密的合同——押金找借口不退、违约金写得天花乱坠、"培训贷"包装成入职培训、住客房被隔成隔断间。我自己就报过一个"先交钱再接单"的兼职项目：条款写着"做不成可退款"，值不值、扛不扛得住，签字前根本没人替你想清楚——好在我当时**逐字看了合同，按条款要回了钱**，但很多同学没有这种运气和边界感。

学生手里没有"过来人的眼睛"：合同密密麻麻几页，看不出哪条不对；找律师太贵，打 12348 又要排队，签约现场等不了。

所以我们做了一个**打开就能用**的工具：把法律条文和踩坑经验做成逐条检查，在签字之前告诉你哪里要问、该怎么问。

## 四、怎么用（4 步）

1. 打开链接 https://kuipan-odzma4gogrf.qoder.zone ；
2. **三选一**：直接点首页的示例合同（不用上传任何东西就能看完整个流程）/ 粘贴合同文字 / 上传 Word·PDF 或手机拍的合同照片；
3. 点开始分析。系统会提示：姓名、手机号、住址等**在本地就抹掉了**，只把脱敏后的文本发给 AI，原始文件不上传；
4. 看结果页：**概览卡 → 红色条款逐条展开**（白话解释 / 法条原文+来源 / 签约前话术 / 改写建议）→ 点「查看同类案例」进陷阱库，把签约前检查清单逐条勾完再去签字。

## 五、怎么用 Qoder 做出来的

**一个人、3 天、从 0 到公网可用**，全程在 Qoder Desktop 里完成。大致是这样分工的：

**① 策略层与执行层分开对话。** 先用策略对话把产品定位、六条不可动摇的架构约束、里程碑排期全部冻结成计划文件，再由单独的执行对话读取计划生成仓库内的 AGENTS.md。执行层只实现、不擅自改架构——比如"法律依据永远只从规则库读取，模型只返回命中编号"这条防幻觉铁律，3 天里没有被任何一次"顺手优化"突破过。例如 M3 引入语义匹配时，模型仍然只返回命中编号，法条原文依然从规则库读取。

**② 里程碑连续推进。** M0 用探针接口先实测平台边界（Function 能否外网调百炼、请求体上限、网关超时），结论直接决定后面主路径怎么写；M1 纯函数核心+测试；M2 视觉落地+首次发布公网；M3 模型语义匹配+批次并行+失败降级；M4 真实规则库和陷阱库+法条逐字核对；之后进入体验打磨。每个里程碑 commit+tag+bundle+GitHub 备份。

**③ 界面迭代靠"说人话+截图"。** 大量改动就是一句话，例如：
「视觉方向我现在就定：A 卷宗（米白底+墨黑正文+单一朱红强调），直接写 design-spec 铺开页面」；
「这里改回原来的，要钟馗露出全脸」；
「支持上传手机拍的合同照片，识别成文字后进入现有分析流程，不要自动分析，OCR 难免有错字」。
Qoder 按需求改码、本地起服务实测、发布，我在预览里继续批注，一来一回当天闭环。

**④ 验证不依赖承诺。** 每轮改完跑 QA 脚本（headless 双视口 golden path、控制台 0 error 断言），线上版本再用真实浏览器无痕复验；法条依据全部由执行层与官方全文逐字比对并登记核对底本后才在页面显示来源链接。禁用词扫描进构建：我们自己的文案里出现"违法/保证/没问题"这类词会直接构建失败。

**⑤ 部署与运维。** Qoder Sites 一条链路：prepare → publish → 公网，Function 托管脱敏文本的模型调用，Secrets 里自己填 API Key（密钥从头到尾不进聊天记录、不进代码仓库）。
