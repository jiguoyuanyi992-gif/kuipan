# 设计规范 · 馗判（Kuí Pàn）

品牌：**馗判**，副标「签字之前，先照一照」。导航三项：首页 / 捉鬼录 / 照契。
本文件由策略层 2026-11-16 界面重做指令取代原「A 卷宗」方向，是后续所有页面的唯一视觉依据；不得在单个页面临时改设计变量。样式统一消费 `--site-*` 与 `--paper-*` CSS 变量（globals.css 管理）。

## 1. 风格总则

- 国风、帅、不恐怖。墨黑底、宣纸色、朱砂红，少量金色点缀。
- 所有文字用 HTML 排版，不画进图片；**竖排（.vertical-rl）只用于标题与印章，正文一律横排**。
- 竖向滚动。第一版静态：`--site-motion=0`，不做动画，只保留必要的点击切换。
- 契约正文、卷轴、输入卡写在「宣纸面板」（.paper）上；纸内变量自动换纸色，逻辑组件无需感知主题。

## 4. 字体

- 标题：思源宋体（Noto Serif SC，OFL），weight 600，子集化自托管 `public/fonts/title-serif.woff2`，`font-display: swap`。
- 正文：系统字体栈零加载。不引入正文 CJK webfont。
- 印章（.seal）：朱砂方印 + 竖排 HTML 印文；`seal-red.png` 到位后作印面底图。

## 5. 字号 / 间距 / 圆角

沿用原阶梯（`--site-type=1`、`--site-space=1`）；圆角 `--site-radius=4px`；不做胶囊大圆角、渐变背景、玻璃拟态、发光描边。分区靠细线与留白。

## 6. 页面结构

- **全局**：SiteHeader（印章品牌 + 三项导航）/ SiteFooter（固定提示行「AI参考意见，不构成法律意见。」+ 展开区放逐字完整免责声明与照片隐私说明）。
- **首页**：钟馗判官主视觉（zhongkui.png，未到位用墨色占位）+ 中央「呈上生死簿」上传入口；四种输入（粘贴 / Word·PDF / 照片≤6张 / 示例）流程与提示文案不变；示例标注「示例，虚构」。
- **结果页**：判词批注风——概览卡与条款写在宣纸上，朱笔圈注命中句，风险详情为朱砂左批线卡片；「查看同类案例」跳照契对应类型卷轴。
- **捉鬼录**：圆形青铜照妖镜（mirror 位）+ 当前鬼画像（ghost-*.png）；信息卡字段：鬼名 / 比喻 / 常出没 / 应对策略；下方缩略图点击切换。数据 `data/ghosts.json`。
- **照契**：先选合同类型，再展开卷轴（CSS 渐变绘制上下木轴 + 两端圆形轴头 + 左右细窄裱边 + 宣纸色纸面，纸纹用 CSS 渐变，不引用外部图片；见第 8 节）；检查清单在卷轴上方（勾选沿用 `qqy:checklist:*`），每条前置 2~4 字「重点标签」小色块（5 类固定色，见第 8 节）；卷轴两栏：注意事项（法律依据，只按 rule_id 读规则库且仅 verified=true，否则「整理中」）/ 典例分析（左「典例来源」链接盒右标题概要，下方整宽分析，重要词变红；见第 10 节）。数据 `data/contracts.json`，法条不复制原文。套餐 / 考证 / 保险无数据，整卷「整理中」。

### 8.3 清单重点标签（5 类固定色）

每条清单句子前置 2~4 字标签，浅底（`#fefdf8`）+ 深色字 + 同色细边框，宽度按最长 4 字固定（句子左对齐），宋体系 600 字重。全站只用以下 5 色：

| 类别 | 色值 | 含义 | data-cat |
|---|---|---|---|
| 主体 | `#B23A2E` 朱砂红 | 签约人身份、房屋性质 | `subject` |
| 金钱 | `#9A6B1F` 赭金 | 押金、水电网费用、付款方式 | `money` |

- 标签文字与浅底对比度均 ≥ WCAG AA（最浅的赭金 `#9A6B1F` 对 `#fefdf8` ≈ 4.6:1）。

## 9. 捉鬼录 · 照妖镜镜框与焚鬼切换动画（2026-11-17 天赐指令）

只改样式与动效，文案、数据、路由不变。实现见 `src/globals.css` 的 `.ghost-*` 段与 `src/pages/GhostsPage.tsx`；素材 `public/assets/ghost-*.png` 共 13 张（九尾狐图已到位）。

### 9.1 镜框（扁平国风镜框图，2026-11-17 天赐二次指令替换）

- 镜框改为图片素材 `public/assets/mirror-frame.png`（`gen_mirror.py` 生成的 `flat_frame_v3_01` 量化版，640px／164KB）：外圈素边＋连珠纹＋回纹带，两色扁平（哑光古铜 on `#3B2B20`），无镜钮、无丝绦、无渐变；原内联 SVG 八卦纹/镜钮/丝绦方案整体废弃。
- 几何：按实测图定 `--hole: 0.547`（内孔直径/图宽）与外圆/内孔半径比 1.532；`.ghost-mirror` 边长 = `--face / --hole`，`.ghost-face` 以 `inset: calc((100% - var(--face)) / 2)` 居中，镜心圆恰好嵌进图的内孔。
- 镜框图铺满镜盒后用 `radial-gradient` 环带 mask 只留框体圆环（内孔与外圆之外透明），四角不露底色；`z-index: 3` 盖在镜面上方、`pointer-events: none`。
- 镜面尺寸口径不变：`--face` 桌面 16rem、手机端 `min(13rem, (100vw - 2rem) × --hole)` 等比缩小，375px 视口无横向溢出。
- 镜面：暗底径向渐变＋`.ghost-sheen` 左上冷白微光与边缘暗角保留不变，承担凸面反光感。

### 9.2 焚鬼切换动画（单次焚烧，总时长 500ms；2026-11-17 天赐修订）

- 单次火边扫过：只烧一次。同一条分界线自镜面底部向顶部推进，旧鬼在上、新鬼在下叠放——上面烧掉多少，下面就露出多少，无缝衔接（2026-11-17 之前的两段式「先烧完旧、再倒烧新」已废弃）。
- 烧纸质感（不再是均匀亮条的「激光」感）：分界线处为不规则亮余烬线（`#ghost-fire-jag` 弱扰动），线上方火舌窜入未烧区（`#ghost-flames`，`#ghost-flame-jag` 强扰动 + screen 混合），线下方贴刚烧过的焦黑炭边渐变（`.ghost-char`，遮住 mask 直切缝）与一缕灰烬（`.ghost-ash`），整体辉光 `.ghost-fire-glow`；两个湍流滤镜内 `feTurbulence seed` 以 SMIL discrete 跳变做火苗闪动，无 JS 参与。
- 250ms（分界线扫到中线）处下方信息卡同步换成新鬼内容，150ms 淡入（`.ghost-card-swap`）。
- 驱动方式：两层鬼像 + CSS 自定义属性 `--burn`（`@property` 注册，0→1）同帧驱动两层 mask-image 渐变边界与火边 top 位置；只动 mask/opacity，不动布局属性。鬼像全部预加载。
- 中断规则：动画中点另一只鬼，立即把当前已烧出的目标鬼整体坐实为旧鬼（分界线归零），对它重新起烧完整 500ms——任一时刻画面只有一张完整鬼像，不排队、无残影；点当前已选中的鬼不触发。
- `prefers-reduced-motion: reduce`：关闭火焰与 mask，改 150ms 淡入淡出。
- 火边限制在圆形镜面内（镜面 overflow hidden），各火部件尺寸随 `--face` 按比例缩放，手机端自动等比。
