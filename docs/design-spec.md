# 设计规范 · A 卷宗（签前一查）

用户已预先选定方向 **A 卷宗**：米白底 + 墨黑正文 + 单一朱红强调；极少装饰，靠细线与留白分区。本文件是后续所有页面的唯一视觉依据，不得在单个页面临时改设计变量。样式统一消费 `--site-*` CSS 变量（globals.css 工程样式管理，工作台只临时覆盖）。

## 1. 配色

| 角色 | 变量 | 值 | 说明 |
|---|---|---|---|
| 米白底 | `--site-bg` | `#F7F3EA` | 页面底，暖米白 |
| 纸面 | `--site-surface` | `#FCFAF3` | 卡片/条款纸面，略浅 |
| 墨黑正文 | `--site-fg` | `#1C1B18` | 正文与标题 |
| 次要文字 | `--site-muted` | `#6B675E` | 暖灰，辅助说明 |
| 细线 | `--site-border` | `#E2DCCE` | 1px 分区线 |
| 朱红强调 | `--site-accent` | `#B3261E` | 唯一品牌强调色 |
| 强调上文字 | `--site-on-accent` | `#FFF7F0` | 朱红底上的文字 |

不做渐变背景、玻璃拟态、发光描边。装饰仅靠细线（1px `--site-border`）与留白。

## 2. 风险色与图标映射（不得只靠颜色，每档图标 + 文字）

| 档位 | 色 | 图标 | 文字 | 条款背色 |
|---|---|---|---|---|
| high | `#B3261E`（朱红） | ⚠ | 需重点留意 | `#F6E3DF` |
| medium | `#B26A00`（赭黄） | ! | 建议留意 | `#F3EAD3` |
| low | `#6B675E`（墨灰） | ○ | 可留意 | `#ECE7DB` |
| 零命中 | `#6B675E`（墨灰） | ✓ | 暂未发现明显风险 | 无背色 |

风险色为功能信号，朱红仍是唯一品牌强调色。命中句下划线用对应风险色（2px）。条款目录圆点同色 + 图标。

## 3. 字体

- **标题**：思源宋体（Noto Serif SC，OFL 免费商用），weight 600，**子集化自托管** `public/fonts/title-serif.woff2`，仅覆盖标题/ headings 用字，`font-display: swap`。
- **正文**：系统字体栈，**零加载**：`-apple-system, "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", "Noto Sans CJK SC", sans-serif`。
- 不引入正文 CJK webfont（避免数 MB 加载）。

## 4. 字号阶梯（rem，`--site-type=1`）

| 用途 | 尺寸 | 行距 |
|---|---|---|
| 页标题 h1 | 2.25 (text-4xl) | 1.3 |
| 区块标题 h2 | 1.5 (text-2xl) | 1.35 |
| 卡片标题 h3 | 1.125 (text-lg) | 1.4 |
| 正文 | 1 (text-base) | 1.75 |
| 辅助 | 0.875 (text-sm) | 1.6 |
| 免责/脚注 | 0.75 (text-xs) | 1.7 |

## 5. 间距 / 圆角 / 阴影

- 间距基数 4px（`--site-space=1`）；区块间 24–32px，卡片内 padding 16–20px。
- 圆角克制：`--site-radius=6px`；徽标 4px；不做胶囊大圆角。
- 阴影克制：`0 1px 2px rgba(28,27,24,.06)`；不用发光/多层重阴影。
- 分区靠 1px 细线 + 留白，不靠重卡片堆叠。

## 6. 布局

- 桌面：结果页左目录（条款红黄绿）+ 右原文与详情；最大宽 1100px 居中。
- 移动（≤768px）：目录折叠为顶部横向滚动标签或可展开列表，原文与详情纵向堆叠；无横向溢出。
- 输入页：粘贴文本框 + 上传（Word/PDF）+ 3 份示例一键 + 高命中演示合同入口；分析按钮上方明示「分析时会把脱敏后的文本发送给 AI 服务」。
- 示例与演示合同在入口与结果页顶部均标注「示例，虚构」。

## 7. 文案约束（与 AGENTS.md 一致）

- 总体三档：需重点留意 / 建议留意 / 暂未发现明显风险（不得出现「安全」）。
- 页头页脚免责声明逐字。
- 模型改写标注「AI 生成，仅供参考」；其他可疑条款弱样式、措辞「建议留意」、不附法律依据。
- 法律依据仅 `verified: true` 显示（M1/M2 假规则全 false，故 M2 不显示法律依据区块）。
